## About

Personal portfolio of **Gustavo Constante**, a full stack developer and Computer Science student at UNESC (Sombrio, SC, Brazil). The site presents my background, featured projects, the stack I use day to day and a contact form.

Published at [gstvdc.github.io](https://gstvdc.github.io) as a static site, generated by Next.js and deployed to GitHub Pages.

## Highlights

- **Three languages:** Portuguese, English and Spanish, with a PT / EN / ES switch. The choice is saved in the browser and, on the first visit, follows the browser language. It even covers the text drawn inside the 3D scene.
- **Projects sorted by last commit:** the data (commit date, published site) comes from the GitHub API **at build time**, with no calls in the browser. The deploy runs every day to keep the order up to date.
- **Interactive 3D stack:** a three.js machine that shows the layers of a feature, loaded only when the section nears the screen.
- **Careful motion:** smooth scrolling (Lenis), a hero name that travels across the screen, word-by-word title reveals, marquees and parallax. Animations pause off screen and respect `prefers-reduced-motion`.
- **Real mobile support:** on phones and tablets the scroll-pinned sections become stacked layouts (the career timeline turns into a vertical list, with no effects that jitter on touch).
- **Contact:** a Formspree form and an interactive globe (d3-geo) centered on Sombrio, SC.
- **Lightweight:** JPG images up to 1200px wide, heavy libraries loaded on demand and no API calls in the browser.

## Getting started

Requires Node.js 20 or later.

```bash
git clone https://github.com/gstvdc/gstvdc.github.io.git
cd gstvdc.github.io
npm install
npm run dev
```

The site opens at <http://localhost:3000>.

| Command | What it does |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Generates the static site in the `out/` folder |
| `npm start` | Serves the `out/` folder locally (run the build first) |
| `npm run typecheck` | Type checking with TypeScript |

## Structure

```text
app/                layout (metadata, fonts) and page
components/         sections (Hero, About, Projects, Skills, Resume, Contact, Footer) and effects
components/ui/      reusable pieces: timeline, 3D scene, globe, Split...
lib/                project data, GitHub (build time), scroll, animation and icons
lib/i18n/           languages: provider, useI18n hook and the pt, en and es dictionaries
styles/             per-section CSS, plus motion.css and theme.css
public/             images and the résumé PDF
.github/workflows/  deploy to GitHub Pages
AGENTS.md           guide for coding agents
```

## Content

| What to edit | Where |
| --- | --- |
| Site text (PT, EN, ES) | `lib/i18n/pt.ts`, `en.ts` and `es.ts` (`pt.ts` defines the structure; the others follow its type) |
| Projects (link, stack, image) | `lib/projects.ts`; each project's text lives in `projects.items` in the dictionaries |
| Experience and education | `resume.items` in the dictionaries and the ids in `components/Resume.tsx` |
| Résumé PDF | `public/docs/gustavo-constante.pdf` |
| Contact form | Formspree, in `components/Contact.tsx` |

To add a project: add it to `PROJECTS` (`lib/projects.ts`), put the image in `public/img/` (JPG up to 1200px wide) and write `summary` and `category` in `projects.items` for all three languages. Private projects without a repository accept `lastCommit` to set their position in the list.

## Deploy

The [`deploy.yml`](.github/workflows/deploy.yml) workflow runs `npm ci && npm run build` and publishes the `out/` folder to GitHub Pages on every push to `main` and once a day (to refresh the last-commit ordering).

Under **Settings → Pages**, the source must be set to **GitHub Actions**.
